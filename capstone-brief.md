# Capstone Brief

## Project Name
DevQuest

## Problem It Solves
People who want to learn to code don't know which language to start with, and have no easy way to track their progress or test what they've learned.

## Who Uses It
A high school student with zero coding experience who wants to build their first app but doesn't know where to start.

## Feature 1
What it does: User describes what they want to build, and the AI recommends which coding language to start with.
What it outputs: A language recommendation with a short explanation and first steps to begin learning.

## Feature 2
What it does: Lets a logged-in user mark a coding language as "Learning" or "Completed" and save it to their profile.
What it outputs: A personal dashboard showing their language list with status, saved to Firestore.

## Feature 3
What it does: Gives the user a short quiz on the language they're currently learning to check their understanding.
What it outputs: A score and result with feedback on what they got right or wrong.

## Tools From This Course It Uses
Firebase (Auth, Firestore, Hosting), PromptAnything, OpenCode in Antigravity IDE, GitHub, Netlify.
